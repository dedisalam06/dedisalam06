2. **Katalog Resmi PrimeNG & Sakai-NG:** Memanfaatkan komponen baku PrimeNG (, , , , ) dengan parameter props yang terukur dan presisi.

5. **Optimasi Aset 3D WebGL & CGI:** Menjaga budget performa aset 3D Blender/Three.js (GLB < 1.5MB, draw calls terkontrol, 60 FPS stabil tanpa memory leak).
